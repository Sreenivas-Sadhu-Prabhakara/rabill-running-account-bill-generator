    Bring in a bill of quantities

    A CSV file exported from a spreadsheet. The first row names the columns — item number, description, unit, contract quantity and rate, in any order and under whatever headings the spreadsheet uses. Rates may carry currency signs and lakh commas. Every row that cannot be used is reported by its line, and the rest still come in.

    Does the account add up?

    Every bill claims the work done to date less everything the previous bill was certified at. So the bills of this contract, added together, must come to exactly the figures the last bill stands at — on every line, to the last paise. This is that check.

    Where this contract is kept

    One file on this machine, written whole every time something changes. Nothing is sent anywhere, and this tool makes no outbound network calls of any kind. It prepares a bill for you to submit yourself.
